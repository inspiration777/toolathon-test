# Junteng Liu — Personal Homepage

This is the personal academic homepage of **Junteng Liu**, a first-year PhD candidate in Computer Science at the Hong Kong University of Science and Technology (HKUST), and a member of the HKUST NLP Group.

This site was built by forking the [Academic Pages template](https://github.com/academicpages/academicpages.github.io) (a GitHub Pages/Jekyll theme based on [Minimal Mistakes](https://mmistakes.github.io/minimal-mistakes/)).

## Contents

- **Home (about)**: Biography, education, research experience, research interests, skills, awards, publications, and contact information.
- **Publications**: Full publication list (available both on the home page and the dedicated Publications subpage).
- **CV**: A compact curriculum vitae.

## Site structure

- `_config.yml` — Site-wide configuration and author/sidebar details.
- `_data/authors.yml` — Author profile data.
- `_data/navigation.yml` — Top navigation menu.
- `_pages/about.md` — Home page content.
- `_pages/cv.md` — CV page content.
- `_pages/publications.html` — Publications listing page.
- `_publications/` — Individual publication entries.

## Running locally

```bash
bundle install
bundle exec jekyll serve
```
